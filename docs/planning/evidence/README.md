# Evidence

Dated receipts that prove a claim made elsewhere in the docs, such as test
output, a labeled-session accuracy report, or a packet-rate measurement.

Name each receipt `YYYY-MM-DD-short-claim.<ext>`, using the date the evidence
was captured. Receipts are never edited. When newer evidence replaces older
evidence, add the new receipt beside the old one and update the page that
cites it.

A receipt that proves a requirement names the requirement's ID, such as
`GRM-001`, so the [quality attributes](../../architecture/quality-attributes.md)
page can cite it.
